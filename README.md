# vota_dolores_hidalgo

Proyecto hecho con Flutter.

## Cómo correrlo

1. Instalar Flutter: https://docs.flutter.dev/get-started/install
2. Clonar el repositorio y abrir la carpeta en VS Code.
3. Descargar las dependencias:

```
flutter pub get
```

4. Ejecutar la app con un emulador o un celular conectado:

```
flutter run
```
